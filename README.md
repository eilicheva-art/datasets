# Datasets description

## russian_regions_stats_2024.csv

В датасете представлены данные по 85 субъектам РФ за 2024 год:
- `Регион` - регион РФ;
- `ФО` - федеральный округ;
- `х1` - среднедушевые денежные доходы (в рублях) [ссылка](https://rosstat.gov.ru/folder/13397);
- `x2` - доля городского населения в общей численности населения (%) [ссылка](https://rosstat.gov.ru/folder/12781#);
- `х3` - численность населения с денежными доходами ниже величины прожиточного минимума (в % от общей численности населения  субъекта) [ссылка](https://rosstat.gov.ru/folder/13723);
- `х4` - уровень безработицы (%) [ссылка](https://rosstat.gov.ru/labour_force);
- `x5` - общая площадь жилых помещений, приходящаяся в среднем на одного жителя (кв. м.) [ссылка](https://www.rosstat.gov.ru/statistics/zhilishhnye_usloviya);
- `x6` - Модальный среднедушевой доход, руб. [ссылка](https://rosstat.gov.ru/folder/13723);
- `y` - общий коэффициент рождаемости (число родившихся на 1000 человек населения в промилле (0,1 процента)) [ссылка](https://www.fedstat.ru/indicator/33536).

Источники: [Росстат](https://rosstat.gov.ru/) и [Федстат](https://www.fedstat.ru/).
