# Datasets description

## russian_regions_stats_2024.csv

В датасете представлены данные по 85 субъектам РФ за 2024 год:
- `Регион` - регион РФ;
- `ФО` - федеральный округ;
- `х1` - среднедушевые денежные доходы (в рублях) [ссылка](https://rosstat.gov.ru/folder/13397);
- `x2` - доля городского населения в общей численности населения (%) [ссылка](https://rosstat.gov.ru/folder/12781#);
- `х3` - численность населения с денежными доходами ниже величины прожиточного минимума (в % от общей численности населения  субъекта) [ссылка](https://rosstat.gov.ru/folder/13723);
- `х4` - уровень безработицы (%) [ссылка](https://rosstat.gov.ru/labour_force);
- `x5` - общая площадь жилых помещений, приходящаяся в среднем на одного жителя (кв. м.) [ссылка](https://www.rosstat.gov.ru/statistics/zhilishhnye_usloviya);
- `y` - общий коэффициент рождаемости (число родившихся на 1000 человек населения в промилле (0,1 процента)) [ссылка](https://www.fedstat.ru/indicator/33536).

Источники: [Росстат](https://rosstat.gov.ru/) и [Федстат](https://www.fedstat.ru/).

## CustomerRScale_rus.csv

Датасет содержит данный о 955 респондентах из исследования удовлетворенности покупателей программными продуктами SPSS. 
Список переменных (не исчерпывающий):
- `Intgresp`	-	Продукты SPSS являются неотъемлемой частью работы
- `Jobeasy`	-	Продукты SPSS делают работу легче
- `Gdvalue`	-	Продукты SPSS обладают большими достоинствами
- `Hiqualty`-	SPSS предлагает продукты высокого качества 
- `Statneed` -	SPSS содержит все необходимые статистические процедуры
- `Easylrn` -	Работе с SPSS легко обучиться
- `Easyuse` -	Продукты SPSS легко использовать
- `Update` -	Продукты SPSS часто обновляются
- `Satinfo` -	Я удовлетворен информацией о новых продуктах
- `Gdprice` -	Продукты SPSS стоят столько, сколько они должны стоить 
- `License SPSS` -	предлагает гибкие условия работы по лицензии
- `Shipget SPSS` -	всегда предоставляет обещанные продукты 
- `Shipcomp SPSS` -	всегда осуществляет точные и полные поставки продуктов
- `Satcomun` -	Я удовлетворен общением с SPSS по поводу возникающих проблем
- `Techsat` -	Я удовлетворен технической поддержкой
- `Jobtype` -	Тип работы
- `Orgntype` -	Тип организации
- `Degree` -	Образование
- `endorse` -	«Будете ли вы снова приобретать продукты SPSS?» (Значения: Да/Нет/ Не знаю).

Значения для первых 14 переменных: 1. Категорически не согласен /2. Не согласен/ 3. Скорее да, чем нет/ 4. Согласен/ 5. Полностью согласен/6. Не знаю. Значения переменной «Тип работы» — 20 различных типов занятий (расчеты, финансы и др.). Значения переменной «Тип организации»: Образование/Правительство/Другая. Значения переменной «Уровень образования»: Неоконченная средняя школа/ …/Диссертация. Значения переменной endorse «Будете ли вы снова приобретать продукты SPSS?» Да/Нет/ Не знаю.
